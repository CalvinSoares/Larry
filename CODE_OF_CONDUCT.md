# Código de conduta

O Larry deve ser um espaço técnico, acolhedor e respeitoso para pessoas com diferentes níveis de experiência.

Esperamos:

- comunicação clara, paciente e construtiva;
- críticas direcionadas ao código, à decisão ou ao problema, nunca à pessoa;
- abertura para perguntas, correções e perspectivas diferentes;
- responsabilidade ao discutir segurança, privacidade e dados de usuários.

Não são aceitáveis assédio, ataques pessoais, discriminação, publicação de informações privadas, ameaças ou comportamento deliberadamente intimidatório.

## Aplicação

Uma pessoa mantenedora pode editar, ocultar ou remover conteúdo que viole este código e pode limitar a participação de quem repetir o comportamento. A decisão deve ser proporcional e explicada quando for seguro fazê-lo.

Para relatar uma violação, envie uma mensagem privada ao mantenedor do repositório pelo GitHub. Para vulnerabilidades técnicas, siga exclusivamente [SECURITY.md](SECURITY.md).
