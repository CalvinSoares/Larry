# Suporte

Use o canal adequado para cada assunto:

- **Dúvida de uso:** GitHub Discussions, quando habilitadas;
- **Bug reproduzível:** GitHub Issues com o template de bug;
- **Proposta de produto ou protocolo:** Discussion ou RFC antes de uma issue de implementação;
- **Problema de documentação:** issue de documentação;
- **Vulnerabilidade:** siga [SECURITY.md](SECURITY.md), nunca uma issue pública.

Ao pedir ajuda, informe a versão, sistema operacional, protocolo, passos de reprodução e o erro técnico original. Remova secrets, tokens, cookies, bodies privados e URLs internas antes de publicar qualquer conteúdo.

O Larry ainda é um projeto comunitário em desenvolvimento. Não há garantia de resposta ou suporte comercial.
